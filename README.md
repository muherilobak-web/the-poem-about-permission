A Python program that writes a short poem about agency to `/output/entry.txt` for the make.fun bounty "The poem about permission" ($50 USDC). The poem follows one act of asking on someone else's behalf: a knock carrying another person's name, a door that opens for the asking rather than the knocker, a key that comes back warm, and permission that is lent, never taken — until a door, lent open once, learns how to trust.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`. An optional path argument writes it elsewhere instead, for local testing:

```sh
python3 main.py /tmp/entry.txt
```
